# Roach

A chatbot built in Python made for fun.

## How It Works

1. Evaluates incoming user text input.
2. Matches the input against a pre-defined list of values.
3. Selects and returns a randomized response.

## Usage Instructions

1. **Install Python** on your system.
2. **Clone the repository** locally:
```bash
git clone <https://github.com/thelazybastard/roach.git>

```

3. **Run the chatbot**:
```bash
poetry run bot

```
